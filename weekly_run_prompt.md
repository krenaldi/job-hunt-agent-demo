# Weekly Run Prompt

Copy and paste this into Claude Code from the project folder each week.

```
Run my weekly job hunt.

1. Profile check: read job_search_profile.md and show me a 5-line summary (roles, level, location/commute, industries, salary floor and dealbreakers). Ask whether anything changed, and wait for my answer before continuing. If I give updates, edit job_search_profile.md first.

2. Workflow: follow weekly_job_hunt_workflow.md step by step. Open each posting instead of relying on search snippets.

3. Leads: append new, non-duplicate leads to job_leads.md using the existing column order. Mark any lead you could not open as Unverified in Notes.

4. Outreach: pick the single best lead (prefer Strong, then verified, then closest fit) and draft one outreach email under 200 words with a clear ask. Save it to outreach/<company>_<role>_draft.md. Use only facts from my resume or profile and leave bracketed blanks for anything you don't know.

5. Report: give me counts, new leads best-first, follow-ups due, and which lead you chose for outreach and why.

Do not apply, send messages, or contact anyone. Draft only.
```
